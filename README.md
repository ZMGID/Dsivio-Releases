# Dsivio Downloads

Dsivio 桌面客户端的公开下载与更新仓库。

[下载最新版本 / Download the latest release](https://github.com/ZMGID/Dsivio-Releases/releases/latest) · [官网 / Website](https://eastforceglobal.com/dsivio/)

当前正式版本：[Dsivio v1.2.6](https://github.com/ZMGID/Dsivio-Releases/releases/tag/v1.2.6)。支持 macOS Apple Silicon（arm64）与 Windows x64；下载页提供安装包与 SHA-256 校验清单。

| 系统 / Platform | 手动安装 / Installer |
| --- | --- |
| macOS Apple Silicon (arm64) | `Dsivio-X.Y.Z-mac-arm64.dmg` |
| Windows x64 | `Dsivio-X.Y.Z-win-x64.exe` |

每个版本的发布说明列出安装方式和已知限制。未签名的 macOS 版本使用 DMG 手动升级。

本仓库只存放下载说明和发行版附件。应用内更新使用同一发行版中的 `latest.yml`、`latest-mac.yml`、安装文件及 `.blockmap`；请将这些附件保留完整。源码及内部构建资料不在此仓库分发。

This repository distributes Dsivio desktop installers and update assets. See each release for installation instructions and known limitations. Unsigned macOS builds require a manual DMG upgrade.
